# LG V30 (joan) proprietary files

Proprietary firmware and radio libraries for the
[LineageOS 24.0 joan port](https://github.com/kernel86-64/android_device_lge_joan),
generated by `device/lge/joan/extract-firmware.sh` from the official
LineageOS 22.2 build and the device's own H930DS firmware.

These files belong to LG Electronics and Qualcomm. They are provided only so
the port can be built. You can regenerate them yourself with the device
tree's extract scripts.
